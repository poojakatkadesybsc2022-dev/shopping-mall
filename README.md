# Shopping Mall Customer Segmentation

## Project Overview
This project uses Machine Learning (KMeans Clustering) to segment mall customers based on their behavior.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Features
- Upload CSV file
- View raw data
- Visualize customer segments
